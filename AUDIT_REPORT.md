## Closure Guarantees & Axiom Kernel (Foundational)

The system formally provides closure guarantees across three dimensions:

1. **Graph-Native Flow**: All external AI interactions and cognitive generation loops execute within LangGraph stateful orchestrator loops (`autoresearch_graph.py`). The inputs/outputs between edges enforce typed `GraphState` immutability, preventing unbounded context drift.
2. **Bicameral Separation**: Execution components (Node sandbox, Docker environment) are fully isolated from cognitive policy components (Hypervisor, Grid ledger). The architecture mandates that any code generation or logic output generated by the cognitive engine is passed over the `/execute` API with hardened isolation (`--network=none`, seccomp restrictions) ensuring no unauthorized egress.
3. **zkML Determinism**: Local edge inferences are provably verified through an `ezkl` Zero-Knowledge Machine Learning (zkML) pipeline. By hashing model weights/bias to a model commitment and producing an off-chain verifier artifact, external Grid peers can deterministically audit the exact reasoning traces without having to trust the local edge Node.
