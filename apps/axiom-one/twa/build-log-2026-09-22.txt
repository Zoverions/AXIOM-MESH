# AXIOM One TWA rehearsal — build log (2026-09-22)

Rehearsal of the PWA → TWA → APK path for AXIOM One, item 7 of the
post-sprint build wave. Built locally at $0 with the real Bubblewrap
toolchain against the placeholder origin
`axiom-one.twa-rehearsal.invalid` (RFC 2606 `.invalid` — can never
resolve) and a throwaway debug keystore.

- Gradle 8.11.1 (wrapper) + Android Gradle Plugin 8.9.1

- Node: system node running the Bubblewrap CLI

## Environment bootstrap notes (this machine)

Three environment-specific workarounds were needed; all are local-only and
do not change what the rehearsal proves:

1. The egress proxy hostname resolves to a dead IPv6 address via
   `/etc/hosts`; the working IPv4 comes from DNS. Java prefers IPv6, so
   every Java network call reset until `-Djava.net.preferIPv4Stack=true`
   was set (sdkmanager, Gradle wrapper, Gradle daemon).
2. Bubblewrap 1.25's SDK validator expects the legacy `tools/` layout
   directly under the SDK root, so the command-line tools were placed at
   `<sdk>/tools/` (not `<sdk>/cmdline-tools/latest/`).
3. Bubblewrap's Gradle wrapper executes `./gradlew` from `process.cwd()`,
   so the build must run with cwd = the generated project directory.

The Android SDK platform and build-tools were installed with
`sdkmanager --install "platforms;android-36" "build-tools;36.1.0"`.

## Explicit non-claims

- `fingerprints` in `twa-manifest.json` is empty: no Digital Asset Links
  statement was published (publishing is Zov-gated). The rehearsal APK
  therefore falls back to a Custom Tab (`"fallbackType": "customtabs"`)
  instead of a verified fullscreen TWA — expected, not a failure.
- The APK was NOT installed on a device and NOT uploaded anywhere. No
  Google Play interaction, no assetlinks publication, no DNS change.
- The debug keystore (`twa-debug.keystore`, alias
  `axiomone-rehearsal-debug`) is a throwaway in local scratch, git-ignored,
  never committed, and must never sign a release build.
- This log proves the local pipeline only. Production origin, release
  keystore ceremony, DAL publication, and Play steps are Zov-gated per
  `RUNBOOK.md` and have NOT been executed.
