# Android/Termux Installation Guide

1. Install Termux + Termux:API (F-Droid)
2. `pkg update && pkg install python git termux-api`
3. `git clone https://github.com/Zoverions/AXIOM-MESH.git && cd AXIOM-MESH`
4. `./install.sh --capsule=skill-pill --platform=android --monitor=minimal-edge`
5. Scan QR for mesh sync + enable 2FA.
