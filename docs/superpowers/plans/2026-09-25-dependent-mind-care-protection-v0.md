Register design and plan.

## CP1 — care profile contract

Add:

- `axiom-dependent-mind-care-profile.v0`;
- strict validator;
- JSON Schema;
- deterministic assessment binding exact Genesis Bond + active guardianship.

## CP2 — required obligations

Require ten exact care dimensions and fail closed on:

- missing/duplicate dimensions;
- privacy/memory boundary violations;
- permanent obedience;
- guardian-only information monopoly;
- guardian as sole dispute reviewer;
- absent independent advocacy;
- absent fallback continuity evidence;
- stale/future evidence;
- overdue review;
- wrong Bond/guardian/dependent/guardianship binding.

## CP3 — non-authority tests

Prove the profile cannot:

- grant memory access;
- create emergency authority;
- create execution authority;
- mutate guardianship;
- mutate developmental status;
- activate Council voting;
- create Genesis eligibility.

## Completion boundary

Stop at `care_obligations_current`.

No live care enforcement, Grid mutation, Gateway route, capability grant, emergency
execution, or capability-registry promotion.
