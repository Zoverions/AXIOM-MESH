# AXIOM-MESH 0.11.0 Release Notes

**Release type:** clean-room production candidate

**Verified source checkpoint:**

## Summary

Version 0.11 adds bounded-cardinality service telemetry, authenticated
OpenMetrics and operations reporting, aggregate dependency readiness,
production secret provisioning, file-backed secrets, a fail-closed
four-process supervisor, and a digest-pinned hardened container candidate.

The supported runtime remains the dependency-free Node.js kernel in `mesh/`.

## Implemented capability highlights

- authenticated intent-to-evidence flow;
- deny-dominant policy and independent high-risk approval;
- encrypted Grid state and signed evidence;
- consent, capsule, memory, local accounting, governance, node, and storage
  records;
- signed scoped portability, staged imports, backup/restore, and offline
  causal sync;
- authenticated operator API and CLI;
- four-service readiness, operations report, OpenMetrics output, and bounded
  alerts;
- explicit external provisioning of service identities, API principals, and
  the data-protection key;
- offline service/API credential rotation and separate data-key re-encryption
  with authenticated rollback and signed disposable-host drill evidence;
- signed policy-derived encrypted-backup retention, recoverable quarantine,
  interruption recovery, and weekly exact-restore evidence;
- real host-mode four-process production drill.

## Container status

The Dockerfile and Compose policy are statically release-gated. The package
uses a digest-pinned Node.js 24.18.0 Alpine base, UID/GID 10001, a read-only
root filesystem, dropped capabilities, no-new-privileges, mounted secrets,
resource ceilings, bounded logs, and permission-restricted Unix-domain host
ingress. A post-baseline 0.11 hardening change uses
`network_mode: none`, fails startup when a non-loopback or IPv4/IPv6 default
route exists, and adds signed protected-CI ingress/egress evidence.
Pilot-platform repetition
and independent review remain promotion requirements.

The image build and composed readiness drill pass in
[GitHub run 30375390450](https://github.com/Zoverions/AXIOM-MESH/actions/runs/30375390450).
This implements the repeatable container package; it does not promote a live
deployment.

## Repository and compatibility change

The supported branch changes from legacy `Main` to clean-room lowercase
`main`. The public baseline has the same source tree as the verified checkpoint
but intentionally has no deprecated parents.

This is a source-history break, not a database-schema reset. Grid schema
version 9 and the documented rollback compatibility rules continue to apply.

## Security action

Any credential from deprecated Git history is permanently compromised and
must be replaced. Do not copy identities, private keys, API tokens, or data
keys from an older checkout.

After the baseline release, the supported line added a keyed 32-entry
deprecated-history inventory and protected supported-tip reuse gate. This
hardens the rolling 0.11 candidate without rewriting the published tag.
Repository revocation is recorded; external custodian/provider attestations
remain required before production promotion.
