# Reversible Low-Consequence Pilot Profile

**Status:** synthetic/controlled pilot architecture only. This is not authentic production-pilot evidence.

The plural-authority roadmap deliberately ends its first implementation sequence with a practical safety gate:

> **Pilot only on reversible, low-consequence workflows before consequential use.**

AXIOM already has a separate production-pilot dossier and evidence-package programme. This profile must not be confused with it.

Its purpose is narrower: prove that the new plural-authority semantics compose correctly in controlled workflows before anyone argues for real consequential use.

## What belongs here

Good candidates include:

- synthetic credential review;
- local previews and simulations;
- reversible local metadata changes;
- test-only recognition;
- non-authoritative proof verification;
- sandboxed contract negotiation;
- draft generation or reversible notification experiments.

Bad candidates include irreversible money movement, public enforcement, real legal/clinical/disciplinary decisions, production access grants, and any self-expanding agent authority.

## Required chain

A pilot case must bind:

```text
scoped synthetic/low-risk workflow
 -> required assurance
 -> policy conflict/downgrade check
 -> explanation available before effect
 -> reversible bounded effect
 -> challenge window + retained evidence
 -> rollback/correction
 -> observations
 -> append-only result
```

## What to measure

The system should record more than success/failure.

Important observations include:

- false allow;
- false deny;
- hold-pending behavior;
- uncertainty preservation;
- conflict visibility;
- downgrade/fallback resistance;
- rollback success;
- reassessment integrity;
- privacy/minimization;
- human comprehension where humans participate;
- operator burden;
- latency/resource cost.

## Promotion firewall

A passing result means only:

> this exact experimental workflow behaved as expected under these exact controlled conditions.

It does not mean:

- production ready;
- safe for irreversible use;
- independently security reviewed;
- legally approved;
- accessible;
- generally interoperable;
- publicly supported.

Every promotion flag is therefore hard-coded false in this profile.

## Relation to authentic pilot evidence

Authentic production-pilot evidence remains governed by the existing pilot dossier/package machinery, dedicated hardware/operations, named roles, long-duration evidence, independent security review, and separate promotion decisions.

Synthetic conformance never substitutes for those gates.

## Governing rule

**Prove composition cheaply where failure is reversible. Escalate evidence before escalating consequence.**
